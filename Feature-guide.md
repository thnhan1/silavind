## Archives Notes

02-Jan-2026

### Description

The **Archives** feature allows you to view all your blog posts organized by year and month, providing a convenient way to browse through your post history.

[![Screenshot-2026-02-07-111714.png](https://i.postimg.cc/hv56ypZN/Screenshot-2026-02-07-111714.png)](https://postimg.cc/Wq05t6v7)

### How to Access
- From the **header menu**: Click on the "Archives" tab
- Direct URL: `/archives/`

### How It Works
1. **Auto-collection**: All posts in the `content/writings/` folder are automatically displayed
2. **Grouped by year**: Posts are organized by year (newest to oldest)
3. **Grouped by month**: Within each year, posts are organized by month
4. **Language format**: 
   - **Vietnamese**: Displays "02 Tháng 1" 
   - **English**: Displays "02 Jan"

### Related Configuration Files
- **Layout**: `layouts/_default/archives.html` or `themes/silavind/layouts/_default/archives.html`
- **Content**: 
  - `content/archives/_index.md` (Vietnamese)
  - `content/archives/_index.en.md` (English)
- **Menu**: Configure in `hugo.toml` under `[params.header.links]` section

### Configuration Example in hugo.toml
```toml
[[params.header.links]]
name = "archives"
url = "/archives/"
```

### Customization
To modify the appearance or behavior of Archives:
1. **Edit layout**: Modify the `archives.html` file
2. **Change styles**: CSS is written inline in the layout file, you can edit `.archives-*` classes
3. **Customize date format**: Edit the `time datetime` section in the layout

## Multi-Language Support

### Overview
This blog theme supports multiple languages out of the box. Currently configured languages are:
- **Vietnamese (vi)** - Default language
- **English (en)** - Secondary language

[![Screenshot-2026-02-07-112406.png](https://i.postimg.cc/D0SnwWtY/Screenshot-2026-02-07-112406.png)](https://postimg.cc/WqcQ94pM)

### Language Configuration

#### In hugo.toml
```toml
languageCode = 'vi'
defaultContentLanguage = "vi"

[languages]
[languages.en]
languageName = "English"
languageCode = "en"
weight = 2

[languages.vi]
languageName = "Tiếng Việt"
languageCode = "vi"
weight = 1
```

**Explanation:**
- `defaultContentLanguage`: Sets Vietnamese as the default language
- `weight`: Determines language priority (lower weight = higher priority, but weight=2 comes first in some Hugo operations)
- `languageCode`: Language code used in HTML lang attribute

### Translation Files

UI translations are stored in `/data/l10n/`:
- `vi.yaml` - Vietnamese translations
- `en.yaml` - English translations

#### Example structure:
```yaml
# data/l10n/en.yaml
home: 'Home'
about: 'About'
writings: 'Writings'
projects: 'Projects'
archives: 'Archives'
search: 'Search'
```

### Creating Multilingual Posts

#### Post File Structure
To create a post in multiple languages, use the following naming convention:

```
content/writings/2025-09-25/
├── my-post.md           # Default (Vietnamese)
├── my-post.vi.md        # Vietnamese explicitly
└── my-post.en.md        # English
```

#### Example Post Content

**my-post.vi.md:**
```markdown
---
title: "Tiêu đề Tiếng Việt"
description: "Mô tả bài viết"
tags: ["tag1", "tag2"]
---

Nội dung bằng tiếng Việt...
```

**my-post.en.md:**
```markdown
---
title: "English Title"
description: "Post description"
tags: ["tag1", "tag2"]
---

Content in English...
```

#### Naming Conventions
- **Vietnamese**: `filename.md` or `filename.vi.md`
- **English**: `filename.en.md`
- Both files can have the **same title** or **different titles** depending on content

### Section Pages (About, Projects, Archives)

Each section should have language-specific versions:

```
content/about/
├── index.md         # Vietnamese
├── index.vi.md      # Vietnamese (explicit)
└── index.en.md      # English

content/archives/
├── _index.md        # Vietnamese
└── _index.en.md     # English
```

### Language Switcher

The theme automatically provides language switching. Users can:
1. **Access Vietnamese**: Visit root URL (e.g., `/`)
2. **Access English**: Visit language-prefixed URL (e.g., `/en/`)

Language-specific URLs:
- `https://example.com/` - Vietnamese version
- `https://example.com/en/` - English version
- `https://example.com/about/` - Vietnamese about page
- `https://example.com/en/about/` - English about page

### Adding a New Language

To add a new language (e.g., French):

1. **Add to hugo.toml:**
```toml
[languages.fr]
languageName = "Français"
languageCode = "fr"
weight = 3
```

2. **Create translation file:**
Create `data/l10n/fr.yaml` with all translated strings

3. **Create content files:**
Add `.fr.md` extension to your content files:
```
content/writings/2025-09-25/
├── my-post.md
├── my-post.vi.md
├── my-post.en.md
└── my-post.fr.md
```

### Using Translations in Templates

In layout files (`.html`), access translations using:
```html
{{ (index .Site.Data.l10n (.Site.Language.Lang)) "key_name" }}
```

Example:
```html
<h1>{{ (index .Site.Data.l10n (.Site.Language.Lang)) "archives" }}</h1>
```

### Best Practices

1. **Keep translations consistent**: Use same tags and metadata across translations
2. **Date format**: Dates automatically format based on language in templates
3. **Content parity**: Try to keep content structure similar between language versions
4. **Frontmatter**: Mirror frontmatter across language versions for consistency
5. **URL structure**: Both language versions maintain SEO-friendly URLs with language prefix
